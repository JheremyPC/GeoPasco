Ejecución

1. Abrir un navegador web actualizado, como Google Chrome, Microsoft Edge o Mozilla Firefox.
2. Ingresar a la siguiente dirección:

https://jheremypc.github.io/GeoPasco/

3. Esperar a que cargue el mapa.
4. El sistema está listo para utilizarse directamente desde la página web. No es necesario instalar programas ni realizar configuraciones adicionales.

Funcionalidades

- Visualización de un mapa interactivo de Cerro de Pasco.
- Búsqueda de lugares y establecimientos.
- Consulta de lugares mediante Google Places.
- Filtrado mediante categorías de Salud, Educación, Gobierno, Seguridad y Comercio.
- Visualización de marcadores sobre el mapa.
- Consulta de información de los lugares seleccionados.
- Obtención de la ubicación actual del usuario.
- Cálculo y visualización de rutas desde la ubicación del usuario.
- Visualización de distancia y tiempo estimado de la ruta.
- Acceso a la ubicación del lugar mediante Google Maps.
- Interfaz adaptable para computadoras, tablets y teléfonos móviles.
